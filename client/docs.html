Pokedex API Documentation

These are the endpoints for my Pokedex API. Click one to see how to use it.

GET, HEAD /pokedex/getAll

URL: /pokedex/getAll

Methods: GET, HEAD

Query params

  • limit (number, optional)
  • offset (number, optional)

Returns: JSON with total, count and an array of pokemon. Sends a 400 if limit or offset is not a number.

Example request:

GET /pokedex/getAll?limit=2

Example response:

200 OK
{ "total": 151, "count": 2, "pokemon": [ { "id": 1, "name": "Bulbasaur", ... }, { "id": 2, "name": "Ivysaur", ... } ] }
GET, HEAD /pokedex/getPokemonByNum

URL: /pokedex/getPokemonByNum

Methods: GET, HEAD

Query params

  • pokedexNum (number, required)

Returns: JSON with one pokemon object. Sends a 400 if pokedexNum is missing or not a number, and a 404 if there is no pokemon with that number.

Example request:

GET /pokedex/getPokemonByNum?pokedexNum=25

Example response:

200 OK
{ "pokemon": { "id": 25, "name": "Pikachu", "type": ["Electric"], ... } }
GET, HEAD /pokedex/getPokemonByType

URL: /pokedex/getPokemonByType

Methods: GET, HEAD

Query params

  • pokemonType (string, required)
  • limit (number, optional)
  • offset (number, optional)

Returns: JSON with total, count and an array of the pokemon that have that type. Sends a 400 if pokemonType is missing or not a real type.

Example request:

GET /pokedex/getPokemonByType?pokemonType=Dragon

Example response:

200 OK
{ "total": 3, "count": 3, "pokemon": [ { "name": "Dratini", ... }, { "name": "Dragonair", ... }, { "name": "Dragonite", ... } ] }
GET, HEAD /pokedex/getPokemonByWeakness

URL: /pokedex/getPokemonByWeakness

Methods: GET, HEAD

Query params

  • pokemonType (string, required)
  • limit (number, optional)
  • offset (number, optional)

Returns: JSON with total, count and an array of the pokemon that are weak to that type. Sends a 400 if pokemonType is missing or not a real type.

Example request:

GET /pokedex/getPokemonByWeakness?pokemonType=Fairy&limit=1

Example response:

200 OK
{ "total": 11, "count": 1, "pokemon": [ { "name": "Mankey", ... } ] }
POST /pokedex/addPokemon

URL: /pokedex/addPokemon

Methods: POST

Body params

  • name (string, required)
  • pokemonType (string, required)
  • img (string, optional)
  • height (string, optional)
  • weight (string, optional)

Returns: The body can be JSON or x-www-form-urlencoded. Sends back a 201 with a message and the new pokemon. Sends a 400 if something is missing or invalid.

Example request:

POST /pokedex/addPokemon
Content-Type: application/json

{ "name": "Fuecoco", "pokemonType": "Fire" }

Example response:

201 Created
{ "message": "Created Successfully", "pokemon": { "id": 152, "name": "Fuecoco", "type": ["Fire"], ... } }
POST /pokedex/changePokemonName

URL: /pokedex/changePokemonName

Methods: POST

Body params

  • pokedexNum (number, required)
  • name (string, required)

Returns: The body can be JSON or x-www-form-urlencoded. Sends back a 204 with nothing in the body. Sends a 404 if the pokemon does not exist, or a 400 if something is missing or invalid.

Example request:

POST /pokedex/changePokemonName
Content-Type: application/x-www-form-urlencoded

pokedexNum=25&name=Pika

Example response:

204 No Content
